# Tendra — pre-launch page (demo)

**Live demo:** https://rafa0071.github.io/tendra-demo/

Fictional brand created as a portfolio piece: a pre-launch landing page for a home, garden and office services marketplace.

- Animated hero: a request is typed, services are detected and offers arrive (Best match / Lowest price / Fastest)
- Two waitlists (customers and providers) with country, individual/business, consent, honeypot spam protection and confirmation
- Automatic language detection (EN, ES, DE, PL, CS) with a manual switch; country names localised
- Launch countdown, cookie consent, GA4-ready events that never include email addresses
- Responsive, accessible, single HTML file with no build step

Tendra is a fictional name; all texts, illustrations and the logo are original.
